# Engineering Portfolio — GitHub Pages

A responsive personal portfolio made with plain HTML, CSS and JavaScript. No build tools, dependencies, or paid hosting required.

## Publish it with GitHub Pages

1. Sign in to GitHub and create a **public** repository named exactly `YOUR_GITHUB.github.io` (replace `YOUR_GITHUB` with your GitHub username).
2. Upload `index.html` to the repository root. You can also upload your CV as `cv.pdf`.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then press **Save**.
6. Wait a few minutes and visit `https://YOUR_GITHUB.github.io`.

## Personalise it before sharing

Open `index.html` and search for these placeholders:
- `YOUR_GITHUB` — your GitHub username
- `YOUR_LINKEDIN` — the part of your LinkedIn profile URL after `/in/`
- `YOUR_EMAIL` — your email address

Replace all occurrences. Update the sample project descriptions and links so they accurately reflect your work. Do not claim project results or skills you have not actually demonstrated.

## Add your CV

Upload your PDF to this repository and name it exactly `cv.pdf`, or change the link in `index.html` to match your PDF filename.

## Cost

GitHub Pages can host this static portfolio for free in a public repository. A custom domain is optional and costs extra; it is not needed to publish the site.
