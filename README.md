# santiagoalvarezv.com

Personal website of Santiago Alvarez, Electrical and Electronic Engineering student at the University of Nottingham.

Live at https://santiagoalvarezv.com

Plain HTML, CSS and JavaScript, served by GitHub Pages. No build step.

- `index.html`: the whole site (home, projects, about, ayrton), in english and spanish
- `img/`: project photos, and `img/rest/` for the ayrton wall
- `wave3.png`, `haze.png`: the circuit wave illustration and its sky haze
- `CNAME`: points GitHub Pages at the custom domain
